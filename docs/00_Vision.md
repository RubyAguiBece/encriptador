# Encriptador Studio

## Visión del producto

Encriptador Studio es una plataforma web para crear, personalizar y compartir mensajes encriptados mediante diferentes algoritmos.

El proyecto nació como un encriptador sencillo basado en un ejercicio de aprendizaje, pero evolucionará hacia una herramienta educativa y creativa para crear experiencias, juegos y desafíos.

---

## Propósito

El objetivo de Encriptador Studio no es únicamente ocultar texto.

El objetivo es permitir que una persona pueda:

- Encriptar mensajes.
- Desencriptar mensajes.
- Experimentar con diferentes algoritmos.
- Crear sus propios sistemas de sustitución.
- Crear desafíos.
- Compartir desafíos.
- Utilizar códigos QR.
- Crear experiencias educativas y recreativas.

---

## Público objetivo

Encriptador Studio puede ser utilizado por:

- Estudiantes.
- Profesores.
- Programadores.
- Iglesias.
- Líderes juveniles.
- Organizadores de juegos.
- Escape rooms.
- Equipos de trabajo.
- Personas interesadas en criptografía educativa.

---

## Principios del proyecto

### 1. Simplicidad

La aplicación debe ser fácil de entender incluso para alguien que nunca haya utilizado un sistema de cifrado.

### 2. Extensibilidad

Agregar un nuevo algoritmo no debe requerir modificar toda la aplicación.

### 3. Experiencia

La interfaz debe ser moderna, clara y agradable.

### 4. Educación

Los algoritmos deben poder utilizarse para aprender conceptos relacionados con la criptografía.

### 5. Creatividad

La plataforma debe permitir crear experiencias y desafíos, no solamente convertir texto.
